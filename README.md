## Aura AI Chat Platform

Designed and developed **Aura AI**, an enterprise-grade AI chat platform focused on secure authentication, persistent conversation management, multimodal interactions, and production-ready deployment.

### Key Features & Contributions

* Implemented **Keycloak-based Single Sign-On (SSO)** with JWT-secured APIs for authentication and authorization.
* Built complete chat lifecycle management including conversation creation, renaming, deletion, search, message editing, regeneration, and custom system prompts.
* Added **multimodal AI capabilities** with image uploads, PDF content extraction, and text file parsing for document-aware conversations.
* Developed persistent conversation memory and real-time streaming responses for an enhanced LLM chat experience.
* Enabled collaboration through **shareable read-only chat links** and chat export functionality.
* Integrated **OpenTelemetry and Arize Phoenix tracing** for LLM observability, monitoring, and debugging.
* Containerized frontend, backend, database, and identity services using Docker for streamlined development and deployment.
* Architected the platform with a scalable deployment path targeting Microsoft Azure services.

### Tech Stack
